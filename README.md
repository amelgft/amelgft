## ✦ how I think

I like learning the **why**, not only the syntax.

I want to understand what happens underneath an abstraction,  
what assumptions a system is making,  
and what happens when those assumptions stop being true.

<pre>
why does this work?

what happens underneath?

what breaks first?

what happens when two requests arrive together?

should the application guarantee this
or should the database?

where should this responsibility live?

what changes when the system grows?
</pre>
